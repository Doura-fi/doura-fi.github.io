Get Status

Query the status of a payment session using its DTID

GET
https://api.doura.fi/checkout/status/{dtid}

Path Parameter

dtidrequiredstring
Doura Transaction ID. Returned from a Create Checkout request.

Response Schema

dtidstring
Doura Transaction ID used to track the session.
statusstring
Current payment status (e.g., pending, completed, failed, expired, etc.).
tokenstring
Payment token type. Echoed from the original request.
amountstring
Payment amount in the selected token. Echoed from the original request.
merchant_addressstring
Merchant's Solana wallet address. Echoed from the original request.
merchant_orderidstring
Merchant's unique order ID. Echoed from the original request.
session_timestampinteger
Unix timestamp when the session was created.
expires_atinteger
Unix timestamp when the session will expire.
redirect_linkstring/null
Redirect URL after payment completion (optional, from original request).
merchant_namestring/null
Merchant display name (optional, from original request).
merchant_logostring/null
Merchant logo URL (optional, from original request).
merchant_emailstring/null
Merchant email (optional, from original request).
onchain_verify_urlstring/null
On-chain verification URL (optional, if available).

Optional fields are only returned if they were provided in the original Create Checkout request.

Status Values

pendingstring
Payment session is active and awaiting payment.
completedstring
Payment has been successfully processed.
failedstring
Payment attempt failed.
expiredstring
Payment session has expired.
cancelledstring
Payment session was cancelled.
