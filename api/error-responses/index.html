Error Responses

HTTP error codes and their meanings for Doura API endpoints

HTTP Status Codes

400string
Bad Request - Malformed request or invalid parameters (e.g., invalid DTID, merchant ATA not found).
409string
Conflict - Nonce reuse detected (possible replay attack).
410string
Gone - The DTID has expired and is no longer valid.
422string
Validation Error - Request body failed validation checks.

Error Details

400 - Bad Request

Returned when the request is malformed or contains invalid data.

DTID-related Error Codes:

DTID_CREATION_FAILEDstring
Failed to create DTID.
DTID_INVALID_TIMESTAMPstring
Invalid timestamp in request.
DTID_NOT_FOUNDstring
DTID does not exist.
DTID_INVALID_FORMATstring
DTID format is invalid.
DTID_MERCHANT_ATA_NOT_FOUNDstring
Merchant's associated token account not found.
DTID_SESSION_NOT_FOUNDstring
Session not found for the provided DTID.
DTID_INVALIDstring
DTID is invalid.
DTID_PARAMETER_MISMATCHstring
Request parameters do not match the existing session.
DTID_SESSION_INVALID_STATUSstring
Session status is invalid for the attempted operation.
DTID_VALIDATION_ERRORstring
DTID validation failed.
DTID_PROCESSING_IN_PROGRESSstring
Operation is already in progress.
DTID_INTERNAL_ERRORstring
Internal system error occurred.

Example Response

{
  "error_code": "DTID_MERCHANT_ATA_NOT_FOUND",
  "message": "Merchant associated token account not found for the specified token",
  "details": "Ensure your wallet has the required token account for USDC/USDT"
}

409 - Conflict

Returned when there is a conflict with the current session state.

DTID-related Error Codes:

DTID_REPLAY_ATTACKstring
Nonce reuse detected - possible replay attack.

Example Response

{
  "error_code": "DTID_REPLAY_ATTACK",
  "message": "Nonce already used — possible replay attack",
  "details": "Each request must include a unique nonce to prevent replay attacks"
}

410 - Gone

Returned when the requested DTID has expired and is no longer valid.

DTID-related Error Codes:

DTID_EXPIREDstring
DTID has expired and cannot be used.

Example Response

{
  "error_code": "DTID_EXPIRED",
  "message": "DTID has expired",
  "details": "Create a new checkout session to continue"
}

422 — Validation Error

Returned when the request body fails schema validation.

Common Causes:

missing_required_fieldsstring
Missing required fields (token, amount, merchant_address, merchant_orderid, nonce).
invalid_data_typesstring
Invalid data types or formats provided.
malformed_jsonstring
Malformed JSON in request body.
invalid_solana_addressstring
Invalid Solana address format (must be Base58, 32–44 characters).
invalid_nonce_formatstring
Invalid nonce format (must be 24-byte Base64 encoded).
invalid_token_typestring
Invalid token type (must be USDC or USDT).
invalid_amountstring
Invalid amount (must be a positive number greater than 0.01).

Example Response

{
  "error_code": "invalid_amount",
  "message": "Amount must be greater than 0.01",
  "details": "Ensure the 'amount' field is a positive number above the minimum threshold"
}
