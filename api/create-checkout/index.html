Create Checkout

Create a secure checkout session for processing payments

POST
https://api.doura.fi/checkout/create-checkout

Request Schema

tokenrequiredstring
Payment token type. Currently supports USDC and USDT.
amountrequiredstring
Payment amount denominated in the selected token (e.g., if token is USDC, the amount is in USDC).
merchant_addressrequiredstring
Your Solana wallet address in Base58 format (32–44 characters).
merchant_orderidrequiredstring
A unique order identifier (alphanumeric, up to 100 characters).
noncerequiredstring
A 24-byte random value, Base64 encoded. Must be unique per request.
redirect_linkstring/null
URL to redirect the payer after payment completion (optional, HTTPS strongly recommended).
merchant_namestring/null
Merchant display name (optional, up to 100 characters).
merchant_logostring/null
Merchant logo URL (optional, must be a valid HTTP/HTTPS link).
merchant_emailstring/null
Email address for payment result notifications (optional, must follow valid email format).

The amount must be greater than 0.01.

Example Request

{
  "token": "USDC",
  "amount": "5.53",
  "merchant_address": "AkskM1kf2QeDrD8WpqZAp1TRNuuKc6ouSZHP6DqXatdt",
  "merchant_orderid": "order_123456",
  "nonce": "UyRth2TN2VzbE0sieksv2YlAuUyxkL0B",
  "callback_url": "https://example.com/webhook",
  "redirect_link": "https://example.com/success",
  "merchant_name": "Test Store",
  "merchant_logo": "http://localhost:3333/pipetil-icon.svg",
  "merchant_email": "test@teststore.com"
}

Response Schema

doura_checkout_urlstring
The URL where the payer is redirected to complete checkout.
tokenstring
Payment token. Echoed from the request.
amountstring
Payment amount. Echoed from the request.
merchant_addressstring
Merchant's Solana address. Echoed from the request.
merchant_orderidstring
Merchant's order ID. Echoed from the request.
dtidstring
Doura Transaction ID. Unique for each checkout session.
session_timestampinteger
Unix timestamp of session creation.
expires_atinteger
Unix timestamp when the session expires.

Nonce Generation

Each request must include a unique nonce to prevent replay attacks.

Requirements:

  • Must be 24 bytes of random data, Base64 encoded
  • Each request must use a new nonce
  • Use a cryptographically secure random number generator

Python Example:

import secrets
import base64

# Generate 24-byte random data and Base64 encode
nonce = base64.b64encode(secrets.token_bytes(24)).decode()
